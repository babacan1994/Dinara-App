DINARA PWA - Kurulum

Bu paket DINARA'yı Android telefona ana ekrandan açılan web uygulaması (PWA) olarak kurar.

- Abone numarası: 00289678
- Kopyalama düğmesi
- FATURA ÖDE: https://online.kibtek.com/
- Kart bilgisi toplamaz veya saklamaz; ödeme KIB-TEK sitesinde yapılır.

GitHub Pages:
1. ZIP'i aç.
2. İçindeki index.html, manifest.webmanifest, sw.js, README_TR.txt ve icons klasörünü
   GitHub deposunun köküne, klasör yapısını koruyarak yükle.
3. Commit changes yap.
4. Settings > Pages > Deploy from a branch seç.
5. Branch main ve folder /(root) seçip Save yap.
6. Yayınlanan HTTPS adresini Android telefonda Chrome ile aç.
7. Chrome menüsünden Install app veya Add to Home screen seç.

Not: PWA kurulumu için HTTPS gerekir. index.html dosyasını doğrudan açmak kurulum için yeterli değildir.
